## 🚀 Featured Projects

### 📊 Expense Tracker App
> A modern personal finance tracker for students and daily budget users

A clean, intuitive mobile app to track daily expenses and income with visual insights. Built with React Native CLI and features a beautiful blue-themed UI.

**Highlights:**
- 💰 Dashboard with balance summary, income/expense toggle & monthly budget progress bar
- 📈 Statistics screen with pie charts breaking down spending by category (Food, Travel, Shopping, etc.)
- 🗂 Add transactions with 10+ categories, date/time picker, notes & payment method (Cash / UPI / Card)
- 🔍 Filter & search transactions; full edit/delete support
- 💾 Persistent local storage via AsyncStorage

**Tech Stack:** `React Native` `React Navigation` `AsyncStorage` `Victory Native` `react-native-vector-icons`

### 🍳 Recipe Finder App
> Discover, search & save recipes — all in one place

A cross-platform mobile app that helps users explore recipes by keyword or ingredient, with a clean modern UI and offline favorites support.

**Highlights:**
- 🔍 Search recipes by name or ingredient
- ❤️ Save favourite recipes locally for quick access
- 📴 Offline-first: Redux + AsyncStorage keeps favourites persistent
- 🖼 Beautifully displays recipe images with smooth navigation
- 📱 Works seamlessly on both Android & iOS

**Tech Stack:** `React Native` `Redux` `Redux Toolkit` `AsyncStorage` `React Navigation` `Axios`
